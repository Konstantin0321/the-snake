# Изгиб Питона (`the-snake`)

Классическая игра **«Змейка»**, реализованная на Python с использованием библиотеки `pygame` и принципов объектно-ориентированного программирования (наследование, инкапсуляция, полиморфизм).

## Правила игры

- Игровое поле представляет собой сетку размером `640 × 480` пикселей (`32 × 24` ячеек по `20 × 20` пикселей).
- Змейка начинает движение из центра экрана вправо и постоянно движется вперёд.
- При съедании яблока длина змейки увеличивается на 1 сегмент, а новое яблоко появляется в случайной свободной ячейке поля.
- При достижении границы экрана змейка появляется с противоположной стороны.
- При столкновении змейки с собственным телом игра сбрасывается: длина снова становится равна 1, а змейка возвращается в центр поля.

## Управление

| Клавиша | Действие |
| --- | --- |
| `↑` / `↓` / `←` / `→` | Изменить направление движения (разворот на 180° запрещён) |
| `Esc` или закрытие окна | Выйти из игры |

### Основные классы в `the_snake.py`

- `GameObject` — базовый класс игрового объекта (`position`, `body_color`, абстрактный метод `draw()`).
- `Apple(GameObject)` — яблоко с генерацией случайной свободной позиции (`randomize_position()`) и отрисовкой (`draw()`).
- `Snake(GameObject)` — змейка с логикой движения (`move()`), смены направления (`update_direction()`), получения координат головы (`get_head_position()`), отрисовки со стиранием следа (`draw()`) и сброса состояния (`reset()`).

## Установка и запуск

1. Клонируйте репозиторий и перейдите в директорию проекта:
   ```bash
   git clone https://github.com/Konstantin0321/the-snake.git
   cd the-snake
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux / macOS:
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите игру:
   ```bash
   python the_snake.py
   ```
